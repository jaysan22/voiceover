# Voicer Choicer

Browser dubbing game: replace dialogue, keep the music bed, share a take or play with 2–4 friends.

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

- **Catalog** — original parody scenes (not licensed movie clips)
- **Solo dub** — karaoke script, mic mix, download
- **Pack Studio** — import video, split dialogue vs bed, mark VO timestamps, save to this browser
- **Party** — room code, claim characters, shared countdown
